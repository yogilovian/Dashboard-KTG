⚠️ Penting untuk GitHub Pages: Agar terhindar dari Error 400: origin_mismatch saat link GitHub dibuka, pastikan URL di atas telah ditambahkan ke menu Authorized JavaScript origins pada Google Cloud Console Client ID Anda.

Jika Anda menggunakan Google Cloud Project sendiri untuk repositori GitHub Anda, masukkan Client ID di sini.
Biarkan kosong jika ingin sistem otomatis membuat spreadsheet baru, atau tempel ID spreadsheet yang sudah ada agar semua HP/tablet terhubung ke file yang sama.
Di GitHub Pages tanpa backend terpisah, biarkan kosong. Aplikasi akan berjalan dalam Mode Mandiri (Direct Sheets) langsung sinkron ke Google Sheets!

Kebijakan Privasi & Kepatuhan OAuth 2.0

  • Prinsip Hak Akses Minimal (Least Privilege): Hanya meminta izin baca/tulis Google Sheets (/auth/spreadsheets) dan file yang dibuat aplikasi (/auth/drive.file). Tidak membaca drive atau email pribadi.
  • Keamanan Token: Sesuai kebijakan Google API User Data Policy, token otentikasi disimpan eksklusif di memori RAM sesi aktif dan tidak pernah disimpan permanen di localStorage atau disalahgunakan.
  • Pencabutan Izin: Petugas dapat mencabut izin kapan saja melalui tombol Putuskan di dashboard ini atau via Akun Google Anda.
📖 Cara Membuat Client ID di Google Cloud Console (3 Menit)
  1. Buka Google Cloud Console → Kredensial.
  2. Klik + Create Credentials → OAuth client ID.
  3. Pilih Application type: Web application.
  4. Pada bagian Authorized JavaScript origins, klik + ADD URI dan tempel URL asal yang sudah disalin di atas (contoh: https://username.github.io).
  5. Klik Create, lalu salin Client ID yang diberikan dan tempelkan ke kolom Client ID di atas.
